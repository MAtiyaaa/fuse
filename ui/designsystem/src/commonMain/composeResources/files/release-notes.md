# Fuse 0.3.2 - The Corner Update

## New

- Nothing new in this one: it is a small fix on top of 0.3.1.

## Changed

- Nothing changed beyond the fix below.

## Fixed

- Home's carousel widgets (Systems, Favourites, New in Library and the others) showed a square
  corner at the top right of the card in front, where the shade behind the widget's name poked out
  past the card's rounded corner. The shade is now cut to the card's shape, so every corner is round.
