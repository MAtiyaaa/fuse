# Fuse 0.2.4 - The Install Update

## New

- **Fuse installs PS3, Vita and 3DS games itself.** A game kept as packages gets an Installed
  Content page (in its options, or Install on its page). It lists the game, its updates and DLC and
  their licences, wherever they are: internal storage, an SD card or a USB drive. It shows what the
  emulator already has, what is left, and any licence that's missing, before anything is tried.
  Install puts everything in with the emulator's own installer, in the right order: licences, the
  game, updates oldest first, then DLC. Each step only counts once Fuse sees it in the emulator's
  storage. Run it again after a problem and it picks up where it stopped.
  - **RPCS3:** `.pkg` games, updates and DLC, with their `.rap` and `.edat` licences. A `.rap`
    under another name is installed under its content id, which is the name RPCS3 looks for.
  - **Vita3K:** `.pkg` with its zRIF (found in a `.zrif`, `.txt` or NoPayStation `.tsv` beside the
    game, made from a `.rif` or `work.bin`, or pasted), and `.vpk` and `.zip` dumps. Updates use the
    game's own licence.
  - **Azahar:** 3DS `.cia` games, updates and DLC. Azahar plays the installed title, never the
    `.cia` itself.
  - On Android these emulators only install from their own menus, so the same page is the guide:
    the files in order, and a button to open the emulator.
- **Game states on the game page:** Ready to play, Needs installation, Missing licence, Update
  available locally, DLC available locally.
- **A startup animation.** Fuse's mark lights like a fuse when Fuse starts. Any button skips it.
  Turn it off in Settings, Appearance; play it again from the developer options.
- **Search RomM from Fuse's search.** With Cartridge installed, the last result is the same search
  on your RomM server, for games on systems your library doesn't have.

## Changed

- PS3 and Vita games kept as `.pkg` files are found, and a Vita `.zip` counts when it holds a Vita
  game. Updates and DLC packages join their game by title id, and so do 3DS update and DLC `.cia`
  files.
- An installed package game starts by its title id, the way the emulator expects, never by
  handing it the package again. Play on a package that isn't installed yet offers to install it.
- The second screen belongs to the app in front. When you switch to another app (Cartridge with
  its own second screen, for example), Fuse's companion steps aside, and it is back on top when you
  return to Fuse.
- Find in Cartridge searches by the game's name only, without region and dump tags, so the game is
  found.

## Fixed

- Opening an app or game on the bottom screen opened it on the top screen when it was already
  running there, or picked a recording or switched-off display.
- An app's icon was cropped in the "Open on which screen?" prompt.
- After updating itself on Android, Fuse didn't come back. It now reopens by itself where Android
  allows it (as the Home app), and otherwise leaves a "Fuse is up to date" notice, one tap from
  opening it.
