# Fuse 0.2.5 - The Ignition Update

## New

- **The startup animation writes Fuse's own name.** Fuse's mark lights like a fuse, glides aside,
  and the Fuse wordmark burns in beside it, white-hot at the edge and cooling behind, until the two
  stand as Fuse's logo, the same one on the website. It fits any screen, follows your theme's
  colours, and with Reduced motion shows the finished logo. Any button still skips it.

## Changed

- The mark at the top left and on the second screen is now drawn exactly as Fuse's logo is.
- A game or app opened on the bottom screen opens there plainly, without the animation that grows
  out of Fuse's window on the top screen.

## Fixed

- After opening a game on the bottom screen, the "Starting" screen covered the top screen and
  ignored the controller for four seconds. It now lifts in about a second, so Fuse is ready again
  right away.
- Opening a game or app on the bottom screen while Cartridge was running showed Cartridge's
  second screen instead. Fixed together with Cartridge 0.9.20, which hands the bottom screen back
  when you leave it.
